### File Formats & Preservation

* Managing working files (.procreate, .psd), exporting standard formats (PNG, JPEG, PDF), and maintaining digital backups to prevent data loss.

---------------------------------
#### Breakdown:
1. Proper file management is super important in digital art because it helps protect the artwork throughout the entire process, from the first sketch to the final version. 

2. When starting a project, artists need to choose the right canvas size and resolution. I learned that 300 DPI is commonly used for high-quality printing, while lower resolutions can work for artwork that will only be viewed online. It is helpful to save the original project in its native format, such as (.procreate) or (.psd), because this keeps the layers and other editable elements available for future changes. 

3. When the artwork is finished (which is the best part), the file format should match how it will be used. 

4. PNG files work well for web images and transparency, while PDFs or TIFFs are commonly used for printing, and JPEGs are useful when a smaller file size is needed. 

*Keeping backup copies through cloud storage, external drives, or different versions of the file can help prevent losing important artwork if something goes wrong with the original file.*
